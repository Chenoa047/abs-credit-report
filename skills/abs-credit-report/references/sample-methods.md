# 按资产类型取材

## 按问题选取原始材料

| 需要核实的内容 | 首选及补充依据 | 常见错配 |
| --- | --- | --- |
| 计划全称、期次、证券档次 | 封面、释义、证券分档表及已有实际发行资料互证 | 文件名前缀可能是某一档简称；名称附注、括号和序号可能在成稿中被简写。按正式文书核实，保留正式计划名。 |
| 发行规模和兑付 | 实际发行或存续披露优先用于实发金额与兑付；首评、说明书用于拟定条款 | 目标券为优先B或次级时，优先级合计仍覆盖其他优先档；实发、存续余额、计划上限和资产池余额分开。 |
| 交易结构和信用增级 | 同期说明书的交易结构、信用增级及触发机制章节；同期评级图及评级分析交叉核对 | 章节号仅供导航。若电子文字仅含水印、空白或乱码，按目录和印刷页码渲染，必要时OCR并核对原页。 |
| 基础资产 | 首评资产池分析；缺项用同期说明书的基础资产及现金流章节；跟踪报告单独说明变动 | 只有跟踪报告时，若缺初始分布，使用同期说明书。必须区分成立日、基准日、评级观察日与跟踪期末。 |
| 核心主体 | 同期评级及跟踪报告；未覆盖的主体或必要事实可查同期说明书的主要参与方章节 | 区分成立时资本、各时点注册资本和实收资本；跟踪“较首评无变化”不提供新金额。财务指标注明年度、季末、合并或单体口径。 |


## 按资产类型写作

### 融资租赁

用租赁合同项下租金请求权及附属权益解释基础资产，核对是否包含未到期租金、回购价款或其他权利。图表按实际披露选取承租人、租赁物、租赁类型、担保、信用等级、剩余期限、利率、还款频率及集中度等维度。将原始权益人兼任资产服务机构或流动性支持承诺人的职责并列呈现，写清流动性支持的受益范围、触发和限额。对租赁公司采用投放、生息资产、资产质量、融资与盈利等有披露的指标。

### 应收账款及保理融资债权

依协议区分直接入池的应收账款及附属权益、保理融资债权和对应贸易应收款。说明基础合同、债权转让、付款确认、回款路径、是否有追索、差额补足或不合格资产回购。区分原始债权人、保理商、直接债务人和承担额外支付义务的主体。概况注明笔数与户数、余额和统计日，关注单笔/单户集中、前五大债权人及债务人、行业、地区和关联交易。池内实际分布与入池资格标准分开表述。定量覆盖结论须注明实际或假设发行利率、费用及情景。

### 信托受益权及数据资产相关增信

说明专项计划买入的信托受益权，底层信托贷款本息及附属权益，以及信托利益如何回到专项计划。项目名称出现“数据资产”时，核对数据资产究竟是质押担保、反担保或其他安排，按协议写其权利层级。先写贷款笔数、借款人及本金/本息余额，再选取贷款期限、利率、担保覆盖和集中度等图表。

分别识别专项计划层的差额支付承诺、信托贷款层的保证担保和数据资产质押或反担保。同一增信人可承担多重责任，但按各合同写明受益人、资金进入哪个账户、何时触发、支付范围、担保限额和触发顺序。质押覆盖部分贷款时，区分笔数和本金占比。担保机构可按所披露的在保余额、直接与间接融资担保、担保放大倍数、代偿率、资本实力、流动性与支持安排评价履约能力。

### 不动产相关信托受益权

分别解释信托受益权、标的债权、各物业和用于还本付息的现金来源。以物业为单位交代位置、权属、用途、面积、出租及运营情况，按材料补充估值、运营收入净额和处置价款；核对资产池统计量与各物业口径。增信按实际条款列示不动产抵押、运营收入质押、差额支付、回售/赎回、外部保证及运营/流动性支持，避免将不同义务合为一种。参与方表列全相关角色，主体正文详写实质承担信用或主要履约义务的公司；如果按用户既有成稿只写部分主体，核实遗漏主体的风险是否已在结构和增信章节说明。
